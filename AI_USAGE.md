# AI assistance disclosure

This prototype was prepared with substantial AI assistance for design, source,
tests and documentation. The submitter must review, understand, independently run
and own the final submission. Do not claim all code was written without assistance.

Two uses of AI must not be confused:

1. AI assisted development of this repository.
2. Optional runtime live LLM calls inside the delivered orchestration system.

Included offline evidence proves deterministic orchestration behaviour, not live
LLM quality. The fixture uses bundled role outputs and explicitly simulated
approvals. API integration is implemented and mock-tested, but no live API keys
or provider run results were available in the creation environment.

Before submitting, add a short record of your own design reviews, changes, local
test results and any live-model run (provider/model, date, outcome; never the key).
